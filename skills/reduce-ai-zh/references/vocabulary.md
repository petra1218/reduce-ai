# 中文机器腔词表（参考，非清单）

这份词表的作用是写作时自然规避，不是逐条替换。任何替代说法反复使用，自己就会变成新的机器腔。用法：命中下列词句时问一句——删掉它，信息量受损吗？不受损就删，受损就把它落实成具体内容。

数据文件，随检出随更新。加词请附上下文说明（见仓库 CONTRIBUTING.md）。

## 空泛开场

| 词句 | 处理 |
|---|---|
| 随着……的快速发展 | 换成具体现象、数据或矛盾开场 |
| 众所周知 / 不言而喻 | 删。真众所周知就不用写 |
| 值得注意的是 / 需要指出的是 | 删，直接说要说的事 |
| 近年来，……受到越来越广泛的关注 | 换成"谁在关注、为什么"，或删 |

## 路标与总结句

| 词句 | 处理 |
|---|---|
| 首先……其次……再次……最后……（成套） | 按真实逻辑推进，多数场合拆掉编号 |
| 综上所述 / 总而言之 / 由此可见 | 结论章本身即总结，段内少用；"由此可见"后接的如果是数据已说明的事，整句删 |
| 一方面……另一方面…… | 语义真对仗才用，机械对仗删 |
| 不难发现 / 容易看出 | 删。"不难"的东西写出来就完了 |

## 膨胀形容与副词

| 词句 | 处理 |
|---|---|
| 显著（提升/提高/改善） | 有统计检验写检验值，没有就写具体变化量和对比基准 |
| 大幅 / 空前 / 极大 | 落实成数字 |
| 强大 / 优秀 / 良好 / 卓越 | 删或换成可验证的表述 |
| 深入（研究/分析/探讨） | "研究了"就够，深不深读者判断 |
| 有效的 / 有效地 | 多数场合删掉不损失信息 |

## 万能动词框架

| 词句 | 处理 |
|---|---|
| 进行了……（分析/研究/探讨） | 直接用动词：分析了、研究了 |
| 对……开展了…… | 同上 |
| 实现了……的提升 | 提升了，且给出从多少到多少 |
| 发挥着……的作用 | 说明具体起了什么作用，或删 |
| 为……奠定了坚实的基础 | 删 |
| 为……提供了有力支撑 | 删或落实支撑的具体内容 |

## 商业话术渗入

| 词句 | 处理 |
|---|---|
| 赋能 / 抓手 / 闭环 / 底层逻辑 | 删，换成实义表述 |
| 深度融合 / 有机结合 | 写清楚怎么结合、在哪结合 |
| 一站式 / 全方位 / 端到端 | 删或具体化 |

## 排比触发器

| 词句 | 处理 |
|---|---|
| 不仅……而且……更…… | 语义真递进才用；多数是平列关系，拆成两句 |
| 四字格连排（稳定可靠、快速响应、易于维护） | 一段最多一组，多数场合改散句 |
| "化"字三连（科学化、规范化、信息化） | 删到只剩实际做到的那一个 |

## 引出虚构的万能句

| 词句 | 处理 |
|---|---|
| 研究表明 / 有研究表明（无出处） | 素材里有出处带出处，没有就删整句 |
| 专家认为 / 业界普遍认为 | 同上，或写明是哪类专家 |
